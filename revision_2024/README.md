This folder contains scripts used to revise the manuscript between 2024-2026 (Samantha Schaffner). The GRS was updated to be computed from European PD GWAS summary statistics posted as a pre-print in 2025, as part of the GP2 project (Leonard et al.). Changes also include updating the EWAS models to adjust for batch and cell type, adjusting for and stratifying by PD case/control status, presenting model diagnostics in the manuscript, and checking differential methylation at co-methylated regions as well as PD candidate genes.
